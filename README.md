# China–Myanmar Diplomatic Discourse Analysis (2011–2024)

This repository contains the data and analysis scripts used in the study:

## Data

The dataset consists of 1,403 publicly available texts from the Ministry of Foreign Affairs of China (2011–2024).

## Contents

- Notebook: BERTopic analysis pipeline
- Data: full dataset and stopword list

## Method

The analysis is based on BERTopic with:
- BGE-M3 embeddings
- UMAP
- HDBSCAN
- c-TF-IDF

## Reproducibility

The analysis can be reproduced by running the notebook step-by-step.

## Note

The data are derived from publicly available sources (MFA of China website).
